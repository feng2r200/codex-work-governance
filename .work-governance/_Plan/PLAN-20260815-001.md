# Release and Reinstall Work Governance 1.2.0

Goal: Bump Work Governance to 1.2.0, merge the current delivery to main, remove covered local branches/worktrees, and reinstall Codex from the current main source after purging stale Plugin state.

## Success Conditions
- Plugin and project version metadata use base version 1.2.0 with a fresh Codex cachebuster where required.
- main contains the current feature delivery and all local branch/worktree HEADs before any local branch/worktree deletion.
- All non-main local worktrees and local branches are removed only after ancestry coverage is proven.
- The old installed Work Governance Plugin/cache/config state is removed or replaced, then Codex lists the current version installed and enabled from the main source path.
- Validation covers tests/static checks, plugin validation, Git state, and installed Plugin identity; Push remains out of scope.

## Tasks
- T-001: Record current repository, worktree, branch, and plugin installation baseline.
- T-002: Bump version metadata from 1.1.0 to 1.2.0 and validate locally.
- T-003: Merge the current delivery to main and prove main covers all local branch/worktree heads.
- T-004: Remove covered local worktrees and local branches without deleting main.
- T-005: Purge stale Work Governance plugin install/cache/config surfaces and reinstall from current main.
- T-006: Verify installed Codex plugin identity and stop at the new-session confirmation gate.
