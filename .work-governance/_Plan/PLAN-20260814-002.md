# deuv-hookless-runtime

Goal: Remove UV and Hook runtime dependency from installed Work Governance tools while preserving local governance execution and historical Plan non-authority handling.

## Success Conditions
- Installed runtime commands execute directly without uv run or .work-governance/cache/uv.
- The plugin no longer registers SessionStart or UserPromptSubmit hooks as runtime dependencies.
- Ordinary schema-v5 local work remains usable without Hook receipts.
- A historical docs/Plan.md is classified as non-authority and does not affect the active Plan goal.
- Tests and docs reflect the implemented hookless direct-tool contract.

## Tasks
- T-001: Create and verify the active implementation Plan and historical docs/Plan.md non-authority fixture.
- T-002: Replace runtime UV invocation and Hook registration with direct executable bootstrap/control flow.
- T-003: Update controller gates, tests, and documentation for hookless schema-v5 runtime behavior.
- T-004: Run isolated validation, review the work, and prepare local delivery without Push or live activation.
