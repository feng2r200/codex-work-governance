# Skill-layer execution contract hardening

Goal: Harden the work-governance Skill layer so non-trivial work is guided by an explicit pre-implementation plan, evidence basis, user-owned uncertainty frontier, execution brief, and per-slice verification before any future controller/schema hardening.

## Success Conditions
- The lifecycle Skill explicitly requires a pre-implementation plan/evidence/uncertainty/execution brief for non-trivial work before file/data/remote mutation.
- The referenced lifecycle documents make user-owned uncertainty confirmation and agent-owned evidence gathering separable and auditable.
- The slice completion contract compares actual results against predeclared plan obligations and validation checks.
- Repository tests or static checks prove the Skill text contract is present without activating or installing a new plugin build.

## Tasks
- T-001: Review the current Skill and lifecycle references against the user's target behavior and identify exact source gaps.
- T-002: Update only Skill-layer source documentation and related documentation/tests to encode the pre-implementation execution contract.
- T-003: Validate the Skill-layer contract with focused tests/static checks and report residual risks before engineering-side hardening.
