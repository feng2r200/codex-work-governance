# Support

Use the repository's issue templates for reproducible bugs and policy
proposals. Before opening an issue, check the README, existing issues, and the
current Skill that owns the behavior.

Please include:

- the plugin version and installation source;
- the Skill or policy boundary involved;
- the expected and observed behavior;
- a minimal, sanitized scenario; and
- the validation already performed.

Do not post credentials, private repository contents, personal paths, full
transcripts, or other sensitive project data. Security reports belong in the
private process described by [SECURITY.md](SECURITY.md).
