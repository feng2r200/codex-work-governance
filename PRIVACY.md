# Privacy

Work Governance is a local Codex policy plugin. It does not itself collect,
store, sell, or transmit personal data, and it includes no telemetry, hosted
service, lifecycle hook, or durable-state engine.

The plugin can guide Codex to read or change project files and use tools within
the user's authority. Data processed by Codex, the operating system, source
control, persistence tools, or other external services remains subject to those
products' policies and the user's configuration.

Optional state, evidence, knowledge, retrospective, or handoff tools own their
own storage and privacy behavior. Work Governance decides when such a
capability may help; it does not bundle one or require a particular provider.
Users should avoid placing credentials, secrets, or unnecessary personal data
in plans, records, logs, evidence, or reports.
