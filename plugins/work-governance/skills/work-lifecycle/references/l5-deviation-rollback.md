# L5 Deviation And Rollback

Enter deviation handling when evidence shows the current route no longer serves
the goal, the acceptance boundary changed, authority is missing, or an artifact
may be unsafe.

Freeze dependent work, name the suspect artifact or decision, state the
falsifiable cause or unknown, and compare minimal containment, causal
correction, alternate route, and rollback. Destructive rollback or cleanup needs
explicit authority for the exact target.
