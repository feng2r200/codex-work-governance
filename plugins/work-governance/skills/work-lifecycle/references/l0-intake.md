# L0 Intake

Name the user-visible goal before selecting a route. Choose:

- `No-Plan` when the work is bounded, low-risk, and has no durable handoff value;
- `explore` when an agent-owned fact can change the path and is locally
  discoverable;
- `ask` only for a blocking user-owned choice;
- `Plan-controlled` when durable state, recovery, coordination, confirmation,
  high-impact authority, or long-running delivery is useful.

If the user supplied a concrete implementation but the product goal,
acceptance, data strategy, or delivery form can still change the route, draft
the smallest decision frontier before writing or admitting a Plan.

If the goal and acceptance are already clear, proceed with the smallest safe
implementation slice rather than blocking on process.
