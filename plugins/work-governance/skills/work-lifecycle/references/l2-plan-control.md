# L2 Plan Control

Use WorkVCS only for Plan-controlled work. No-Plan work makes no WorkVCS calls.

For first admission, include prior useful context from the No-Plan phase:
request or digest, confirmed facts, findings, decisions, constraints, unknowns,
evidence, escalation reason, acceptance anchors, stop triggers, and next action.

Use high-level WorkVCS commands for project binding, Plan admission, Plan
evolution, resume, receipts, and closeout inspection. Treat receipt and closeout
output as mechanical evidence; the model still owns policy, authority, and
quality judgment.

If the required WorkVCS behavior is absent or wrong, stop depending on it. Fix,
rebuild, install, and verify WorkVCS when current authority allows; otherwise
return to the parent or user with the exact blocked capability.
