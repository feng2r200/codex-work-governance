# L6 Closeout And Handoff

Before a completion claim, separate:

- local delivery status;
- validation evidence;
- WorkVCS mechanical state, if a Plan exists;
- activation, push, deployment, or external gates;
- residual risks and unverified areas.

Use `workvcs closeout inspect` for Plan-controlled mechanical evidence, but do
not let it decide readiness. The model must still judge whether the evidence
proves the user's goal and whether any authority is missing.
